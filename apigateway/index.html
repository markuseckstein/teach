API Connect for API Publishers

Publish and manage OpenAPI definitions on API Connect v10 — automation-first, from the apic CLI and the Platform REST API. The UI stays optional.

Mission

Publish the team's openapi.yml files from the command line and CI/CD, export what's deployed, and master the assembly ("custom pipeline") — against the company's v10.0.11 installation with the native DataPower API Gateway.

How this course works

Each lesson is ~15–20 minutes: a small dose of concepts, a hands-on part against your real environment, a recall quiz, and homework. Your teacher is the agent in your terminal (/teach in this directory) — report homework results, paste weird errors, ask anything. The curated source list lives in RESOURCES.md; your progress in learning-records/.

Built from primary sources: IBM Docs, v10 API Explorer, and IBM's example-toolkit-scripts.

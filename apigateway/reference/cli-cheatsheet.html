apic CLI & REST Cheat Sheet

The publish / inspect / download / lifecycle commands, plus the raw REST bootstrap. Print me.

Session

apic identity-providers:list --scope provider --server $MGMT   # find your realm
apic login  --server $MGMT --realm provider/default-idp-2 --username $USER
apic logout --server $MGMT

Orientation (read-only, always safe)

apic orgs:list           --server $MGMT
apic catalogs:list       --server $MGMT --org $ORG
apic draft-apis:list-all      --server $MGMT --org $ORG
apic draft-products:list-all  --server $MGMT --org $ORG
apic products:list-all   --server $MGMT --org $ORG --scope catalog --catalog $CAT

# Output shaping — works on almost every command:
#   --format yaml | json      --fields name,title,state      --output -   (stdout)
# JSON + jq is the automation workhorse:
apic orgs:list -s $MGMT --format json | jq '.results[] | {name, id}'

Publish (Lesson 2)

apic validate product.yaml                                  # lint product + APIs
apic products:publish product.yaml --server $MGMT --org $ORG --catalog $CAT
apic products:publish --stage product.yaml …                # staged, not live
apic draft-products:create --server $MGMT --org $ORG product.yaml   # draft only

Download / export (Lesson 3)

apic products:clone --server $MGMT --org $ORG --scope catalog --catalog $CAT   # everything
apic products:get NAME:VERSION --server $MGMT --org $ORG --scope catalog --catalog $CAT
apic apis:get     NAME:VERSION --server $MGMT --org $ORG --scope catalog --catalog $CAT
apic draft-apis:get NAME:VERSION --server $MGMT --org $ORG      # dev copy from pOrg

Lifecycle (preview — CI/CD lesson)

# staged → published, moving subscriptions from the old version:
apic products:replace --server $MGMT --org $ORG --scope catalog --catalog $CAT \
     OLDNAME:OLDVERSION mapping.txt        # mapping.txt: product_url + plan mapping
apic products:delete  --server $MGMT --org $ORG --scope catalog --catalog $CAT NAME:VERSION

Raw REST bootstrap

# realm names — no auth required
curl -sk https://$MGMT/api/cloud/provider/identity-providers

# token (~8h): needs client_id/client_secret (toolkit creds or apic registrations:create)
curl -sk -X POST https://$MGMT/api/token \
  -H 'Content-Type: application/json' \
  -d '{"username":"$USER","password":"…","realm":"provider/default-idp-2",
       "client_id":"…","client_secret":"…","grant_type":"password"}'

# then: Authorization: Bearer $TOKEN against the Provider API, e.g.
curl -sk https://$MGMT/api/catalogs/$ORG/$CAT/products -H "Authorization: Bearer $TOKEN"

# endpoint discovery: append --debug to any apic command and read the requests

Rules of thumb

SituationReach for
"What's deployed in env X?"products:list-all --scope catalog, or products:clone for the full YAML snapshot
Ship a new API/versionapic validate → products:publish (add --stage for controlled go-live)
Zero-downtime version swapproducts:publish --stage new, then products:replace old
CI job, no toolkit binary/api/token + Provider API with curl
Unknown endpoint or flag--debug, apic <noun> --help, API Explorer

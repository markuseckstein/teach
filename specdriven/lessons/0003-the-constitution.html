Lesson 3: The Constitution

≈20 minutes, hands-on in ~/sdd-playground · builds on Lesson 2

The one idea

The constitution is the only artifact that outlives features. Spec, plan, and tasks are written per feature and consumed; constitution.md is written once and then enforced as a gate — the plan template literally contains a "Constitution Check: GATE: Must pass before Phase 0 research. Re-check after Phase 1 design" section (plan-template.md). Anything you write there gets re-read by the agent on every feature, forever. That's the power and the danger: it's the one place where a vague sentence taxes every future feature.

The enforceability test An article belongs in the constitution only if a reviewer could objectively point at a PR and say "this violates it." "Code should be maintainable" fails — nobody can rule on it. "Generated API code is never edited by hand; fix the contract and regenerate" passes — a diff either violates it or it doesn't. Un-enforceable articles aren't harmless filler: they teach the agent that the constitution is decorative.

What goes in — for your project

The official template wants: numbered Core Principles (non-negotiables marked), additional constraints, a workflow/quality-gates section, and a Governance footer with a version and ratification date. For a Spring Boot + Angular product with an OpenAPI contract in the middle, the articles that earn their place are the ones an agent would otherwise get wrong:

Article (draft)What it prevents
I. Contract-First (NON-NEGOTIABLE) — the OpenAPI document is the single source of truth for the API. Server stubs and clients are generated from it; generated code is never hand-edited.The agent "helpfully" hand-writing a controller or Angular service that drifts from the contract — the exact failure your whole architecture exists to prevent.
II. Backward Compatibility — breaking API changes require a new endpoint version; removing/renaming a field in a released schema is a breaking change.Plans that casually mutate the contract the other repo depends on.
III. Test Evidence — every functional requirement (FR-NNN) maps to at least one test; contract changes require contract tests on both sides."Implemented" meaning "compiles."
IV. Simplicity — no new library, layer, or pattern without a stated reason tied to a requirement.Agent-invented abstractions and dependency sprawl.

Notice what's absent: code style, formatting, folder naming — linters enforce those cheaper. Constitution articles are for decisions an agent could plausibly get wrong at planning level.

Do it

Step 1 — Generate

In VS Code, open ~/sdd-playground, Copilot Chat in agent mode, and run:

/speckit.constitution Create a constitution for a web product with a Spring Boot
backend and an Angular frontend in separate repositories, communicating only
through a versioned OpenAPI contract. Principles: contract-first API development
(OpenAPI is the source of truth, generated code never hand-edited), backward
compatibility for released endpoints, test evidence for every functional
requirement, simplicity (no unjustified dependencies or layers).

Step 2 — Audit what came back (this is the actual exercise)

Open .specify/memory/constitution.md and grade every article against the quality checklist:

  1. Apply the enforceability test to each article. Expect at least one platitude — agents love "code should be well-documented." Delete or sharpen it.
  2. Check the non-negotiable marking survived on contract-first.
  3. Check the Governance footer has a version and today's date.
  4. Ask the agent to fix what you found: "Article N isn't enforceable — rewrite it so a reviewer could objectively rule a PR in violation."

Feedback loop: when you think it's clean, ask Copilot: "Here is a hypothetical PR: it hand-edits a generated Angular API client to add a missing field. Which constitution articles does it violate?" — a good constitution yields an immediate, specific answer (Article I, probably II). A mushy one yields a mushy answer. That round-trip is your test harness for constitutions.

Check yourself

1. Where is the constitution formally enforced as a gate?
2. Which article belongs in a constitution?

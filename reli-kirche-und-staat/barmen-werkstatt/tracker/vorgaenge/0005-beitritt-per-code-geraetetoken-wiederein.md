# 0005 — Beitritt per Code, Gerätetoken, Wiedereinstieg

## Worum es geht

Dreißig Jugendliche müssen in unter zwei Minuten drin sein, ohne Anmeldung. Und wenn
ein Gerät kurz das Netz verliert, muss es dort weitermachen, wo die Gruppe steht.

## Fertig, wenn

- Beitritt über den Kurscode, zusätzlich als QR-Code darstellbar für den Beamer.
- Nach dem Beitritt wählt das Gerät seine Gruppennummer.
- Jedes Gerät bekommt ein zufälliges, nicht rückführbares Token als Cookie; es dient
  allein dem Wiedereinstieg und dem Schreibrecht.
- Ein Gerät, das nach einem Verbindungsabriss zurückkehrt, landet ohne erneutes
  Beitreten im aktuellen Schritt seiner Gruppe.
- Nirgends wird ein Name erhoben.

## Gehört nicht dazu

Schutz gegen absichtliche Störung. Wer den Code kennt, darf mitmachen — es sitzen alle
im selben Raum.

Fenster verschieben & snappen (Windows-Bordmittel)

ShortcutAktion
Win+← / Win+→Fenster in linke/rechte Bildschirmhälfte snappen
Win+↑ / Win+↓Fenster maximieren / minimieren (bzw. in obere/untere Viertel-Ecke, nach seitlichem Snap)
Win+Shift+← / Win+Shift+→Fokussiertes Fenster auf den nächsten Monitor verschieben (gleiche Größe/Position relativ zum neuen Bildschirm). Läuft an den Rändern um.
Win+ZSnap-Layouts-Auswahl öffnen (native Layout-Raster, dann Zahl 1-9 zur Auswahl der Zielzone)
Win+DAlle Fenster minimieren / wiederherstellen (Desktop anzeigen)

Quelle: Snap Layouts — Microsoft Windows Learning Center

FancyZones (PowerToys)

ShortcutAktion
Win+Shift+`Zonen-Editor öffnen (Layout wählen/bauen)
Win+Ctrl+Alt+1-9Ein zugewiesenes Custom-Layout sofort auf den aktiven Monitor anwenden
Win+← / Win+→Fokussiertes Fenster zwischen Zonen bewegen — nur wenn Override Windows Snap aktiv & Modus Zone index gewählt ist
Win+←/→/↑/↓Fokussiertes Fenster zwischen Zonen bewegen (alle 4 Richtungen) — wenn Modus Relative position gewählt ist
Win+PgUp / PgDnZwischen mehreren Fenstern wechseln, die in derselben Zone gestapelt sind
Ziehen + Shift haltenZonen beim Ziehen per Maus aktivieren (Standardeinstellung)
Ziehen + Ctrl haltenFenster über mehrere Zonen gleichzeitig spannen
Falle Elevated Apps wie Windows Terminal oder Task-Manager lassen sich nur snappen, wenn PowerToys selbst als Administrator läuft.

Quelle: FancyZones Window Manager — Microsoft Learn

PowerToys Workspaces

ShortcutAktion
Win+Ctrl+`Workspaces-Editor öffnen (Setups erfassen/starten)

Ein einzelnes Workspace-Layout wird sonst per Desktop-Verknüpfung oder Taskleisten-Pin gestartet — siehe Lektion 1.

PowerToys Run

Shortcut / PräfixAktion
Alt+SpacePowerToys Run öffnen/schließen
<Window Walker — zwischen offenen Fenstern springen
.Program — App starten, optional mit Argumenten
>Shell — Befehl direkt ausführen
=Calculator — schnelle Rechnung
$Windows Settings — direkt zur Einstellungsseite
#Value Generator — GUIDs, Hashes, Base64
Ctrl+Shift+EnterAusgewählte App als Administrator öffnen
Ctrl+Shift+EEnthaltenden Ordner im Explorer öffnen

Virtuelle Desktops & Task View

ShortcutAktion
Win+TabTask View öffnen (alle Fenster & Desktops im Überblick)
Win+Ctrl+DNeuen virtuellen Desktop erstellen (und dorthin wechseln)
Win+Ctrl+← / Win+Ctrl+→Zum vorherigen/nächsten virtuellen Desktop wechseln
Win+Ctrl+F4Aktuellen virtuellen Desktop schließen (Fenster wandern zum vorherigen Desktop)
Wichtig für dein Setup Ein virtueller Desktop umfasst immer alle Monitore gleichzeitig — Windows kennt keine unabhängigen Desktops pro Monitor. Ohne Gegenmaßnahme verschwinden Outlook/Teams beim Wechseln mit. Details & Lösung: Lektion 3.

Lektion 4 · Windows Multi-Monitor Desktop Management

Workspaces + virtuelle Desktops kombinieren

Der offene Punkt aus Lektion 3: Ein einziger PowerToys-Workspace kann nicht drei Desktops gleichzeitig befüllen. Die Lösung ist kein Kompromiss, sondern mehrere kleine Workspaces — eine pro Kontext.

  2. Der Workaround: vier kleine statt einem großen Workspace
  3. Deine Morgen-Routine, Schritt für Schritt
  4. Für 1-Klick-Ketten vorbereiten
  5. Üben

Der Stand der Dinge: nur der aktuelle Desktop

PowerToys Workspaces positioniert Apps immer auf dem virtuellen Desktop, der beim Start gerade aktiv ist — eine native Zuordnung "diese App auf Desktop Frontend, jene auf Desktop Backend" gibt es (Stand dieser Recherche) nicht. Das ist keine Fehlbedienung deinerseits, sondern eine dokumentierte Lücke: Auf dem offiziellen PowerToys-GitHub gibt es dazu mehrere offene Feature-Requests, u. a. #38221 und #35407.

Einordnung PowerToys wird aktiv weiterentwickelt — es lohnt sich, das bei einem größeren PowerToys-Update erneut zu prüfen. Für jetzt gehen wir vom aktuellen (fehlenden) Stand aus.

Der Workaround: vier kleine statt einem großen Workspace

Statt einem Mammut-Workspace baust du vier schlanke, je einem Kontext aus Lektion 3 zugeordnet:

WorkspaceInhaltLäuft auf Desktop
Dauer-AppsOutlook + Teams, positioniert auf dem Portrait-Monitoregal welchem (wird danach gepinnt)
FrontendVS Code Frontend + Terminal mit Copilot CLIFrontend
BackendVS Code Backend + Terminal(s)Backend
RechercheBrowser (+ optional Terminal)Recherche

Jeden dieser vier baust du genau wie in Lektion 1 beschrieben — nur eben viermal, mit kleinerem Umfang pro Workspace statt einem einzigen großen.

Deine Morgen-Routine, Schritt für Schritt

  1. Nach dem Login: Workspace "Dauer-Apps" starten. Outlook/Teams stehen jetzt auf dem Portrait-Monitor.
  2. Einmal Win+Tab, auf beiden Fenstern "Show windows from this app on all desktops" setzen (siehe Lektion 3).
  3. Zum Desktop "Frontend" wechseln, dann erst Workspace "Frontend" starten.
  4. Zum Desktop "Backend" wechseln, Workspace "Backend" starten.
  5. Zum Desktop "Recherche" wechseln, Workspace "Recherche" starten.
Warum die Reihenfolge zählt Da Workspaces auf dem aktuell aktiven Desktop landet, muss der Desktop-Wechsel vor dem Workspace-Start passieren — nicht danach. Sonst landet z. B. das Backend-Setup versehentlich auf dem Frontend-Desktop.

Macht insgesamt vier Starts plus drei Desktop-Wechsel — unter 30 Sekunden, statt jedes einzelne Fenster von Hand zu ziehen.

Für 1-Klick-Ketten vorbereiten

Pinne alle vier Desktop-Verknüpfungen aus Lektion 1 an die Taskleiste, in der Reihenfolge, in der du sie morgens brauchst. Dann ist die Routine oben rein visuell abzuarbeiten, ohne im Editor suchen zu müssen.

Noch schneller Ganz ohne Taskleiste geht es mit PowerToys Run — siehe Lektion 5.

Unklar — wert, es auszuprobieren Ob der "Show windows from this app on all desktops"-Status einen Neustart übersteht, ist nicht eindeutig dokumentiert. Falls er jeden Morgen neu gesetzt werden muss, ist das nur ein einmaliger Rechtsklick zusätzlich in der Routine — kein Beinbruch, aber gut zu wissen, statt sich zu wundern.

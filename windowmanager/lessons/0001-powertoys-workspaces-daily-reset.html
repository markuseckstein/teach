Das Konzept in 30 Sekunden

Workspaces ist ein PowerToys-Modul, das einen kompletten Desktop-Zustand aufzeichnet: welche Apps offen sind, wo sie stehen, wie groß sie sind — und diesen Zustand auf Knopfdruck wiederherstellt. Technisch startet es jede App neu (oder verschiebt sie, falls schon offen) und positioniert sie anschließend über dieselbe Engine, die auch FancyZones für Zonen nutzt.

Warum das dein Problem löst Ein Workspace übersteht den täglichen Reboot, weil er nichts "merkt" — er baut den Zustand jedes Mal aktiv neu auf. Genau das brauchst du bei täglichem Neustart, im Gegensatz zu Tools, die nur eine laufende Sitzung wiederherstellen.

Einen Workspace erfassen

  1. Öffne den Editor: Win+Ctrl+` (oder über PowerToys-Einstellungen → Workspaces → "Launch editor").
  2. Klicke "+ Create workspace". Der Desktop bleibt voll bedienbar — öffne jetzt genau die Apps, die morgens laufen sollen: Outlook, Teams, VS Code (Frontend-Ordner), VS Code (Backend-Ordner), Terminal(s), Browser.
  3. Ordne jede App auf dem gewünschten Monitor an der gewünschten Position an (per Maus oder mit den FancyZones-Shortcuts, falls du schon Zonen definiert hast).
  4. Klicke "Capture". Du landest im Editor: hier kannst du die Fenstergrößen feinjustieren, Apps entfernen und pro App CLI-Argumente hinzufügen.
  5. Vergib einen Namen (z. B. "Arbeitstag Start") und aktiviere die Option, eine Desktop-Verknüpfung zu erstellen.

CLI-Argumente — damit Apps nicht leer starten

Ein nachträglich verschobenes leeres VS-Code-Fenster bringt dir nichts. Trag im jeweiligen App-Dropdown Argumente ein, damit jede App direkt im richtigen Zustand öffnet:

AppSinnvolles Argument
VS Code (Frontend)/pfad/zum/frontend-projekt
VS Code (Backend)/pfad/zum/backend-projekt
Windows Terminal-p "PowerShell" oder dein bevorzugtes Profil
Browserkommagetrennte Liste von Start-URLs für die Recherche-Tabs

Starten — jeden Morgen mit einem Klick

Nach dem Neustart: Desktop-Verknüpfung doppelklicken (oder an die Taskleiste pinnen). PowerToys zeigt währenddessen eine Statusanzeige pro App — grüner Haken sobald sie steht. Das ist normal und dauert nur Sekunden.

Warum Fenster kurz "aufspringen" PowerToys kann Apps nicht direkt an eine Position starten — es startet sie normal und verschiebt sie danach. Das kurze Springen auf dem Bildschirm ist also kein Fehler, sondern wie das Feature technisch funktioniert.

Stolpersteine für dein Setup

  • VS Code öffnet ein neues Fenster statt das alte zu verschieben. Standardverhalten. Wenn du lieber ein bereits offenes Fenster wiederverwendest, ergänze --reuse-window als CLI-Argument.
  • Terminal als Administrator lässt sich aktuell nicht zuverlässig repositionieren (bekannter Bug). Falls du Terminals erhöht brauchst, plane das separat statt im Workspace.
  • Single-Instance-Apps wie Einstellungen werden immer verschoben statt neu gestartet — unkritisch für dein Setup, aber gut zu wissen.
  • Outlook/Teams als Dauer-Apps: Nimm sie explizit mit in den Workspace auf (inkl. fester Position), statt dich auf ihren Auto-Start beim Windows-Login zu verlassen — so landen sie garantiert auf dem richtigen Monitor und nicht irgendwo.

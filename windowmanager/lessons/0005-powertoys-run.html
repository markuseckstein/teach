Grundidee: Tastatur statt Taskleiste

Alt+Space öffnet PowerToys Run — ein Suchfeld, das je nach Eingabe Apps, Dateien, offene Fenster, Windows-Einstellungen oder einen Taschenrechner durchsucht. Esc schließt es wieder. Der Sinn für dich: bei 4 Monitoren und vielen offenen Fenstern ist "kurz mit der Maus zur Taskleiste fahren und suchen" spürbar langsamer als tippen.

Die für dich nützlichsten Plugins

PräfixPluginWarum für dich relevant
<Window WalkerZwischen offenen Fenstern springen — z. B. < backend findet direkt dein Backend-VS-Code-Fenster unter mehreren offenen Instanzen
.ProgramApp starten, optional mit Argumenten (z. B. VS Code direkt mit einem Projektordner öffnen)
(kein Präfix)Folder / Windows SearchPfad eintippen → Ordner/Datei direkt öffnen, ohne Explorer-Fenster zu durchklicken
>ShellBefehl direkt ausführen, z. B. > ping localhost
=CalculatorSchnelle Rechnung ohne Taschenrechner-App zu öffnen
$Windows SettingsDirekt zur passenden Einstellungsseite springen (z. B. bei Monitor-Problemen zu Anzeigeeinstellungen)
#Value GeneratorGUIDs, Hashes, Base64 — nützlich beim Entwickeln, ohne ein externes Tool/Website zu öffnen
Größter Alltagsnutzen Window Walker (<) ist bei deinem Setup vermutlich das wertvollste Plugin: Bei 2× VS Code + mehreren Terminals über 4 Monitore verteilt ist Tippen des Fenstertitels oft schneller als visuell zu suchen oder Alt+Tab mehrfach durchzuklicken.

Kombo: Workspaces per Run starten

Die Desktop-Verknüpfungen für deine Workspaces aus Lektion 1 sind ganz normale Programme aus Sicht des Program-Plugins. Statt sie an die Taskleiste zu pinnen und anzuklicken (Lektion 4), reicht:

  1. Alt+Space
  2. Namen tippen, z. B. "Frontend"
  3. Enter

Für die komplette Morgen-Routine aus Lektion 4 bedeutet das: Desktop wechseln, Alt+Space + Name + Enter, wiederholen — ganz ohne die Taskleiste anzufassen.

Ausblick: Command Palette

Für später, nicht jetzt Microsoft baut mit der Command Palette einen offiziellen Nachfolger für PowerToys Run (in den PowerToys-Dokus als "PowerToys Run v2" bezeichnet). Für den Einstieg reicht Run vollkommen — falls dich der Umstieg interessiert, machen wir dazu bei Bedarf eine eigene Lektion, statt jetzt beides parallel zu lernen.

Virtuelle Desktops, ohne Outlook & Teams zu verlieren

Frontend, Backend und Recherche sauber trennen — ohne dass Outlook und Teams beim Wechseln verschwinden. Der Trick ist eine einzige Einstellung pro Dauer-App.

Die Grundregel: Desktops sind global, nicht pro Monitor

Anders als man bei 4 Monitoren vielleicht erwartet: Windows kennt keine unabhängigen virtuellen Desktops pro Monitor. Ein virtueller Desktop umfasst immer alle Monitore gleichzeitig. Drückst du Win+Ctrl+→, wechseln alle 4 Monitore gemeinsam auf den nächsten Desktop — nicht nur der, auf dem du gerade arbeitest.

Konsequenz Ohne Gegenmaßnahme würden Outlook und Teams bei jedem Desktop-Wechsel mitverschwinden, egal auf welchem Monitor sie stehen. Genau dafür gibt es den Trick in Abschnitt 2.

Der Trick: Dauer-Apps auf allen Desktops zeigen

  1. Task View öffnen: Win+Tab.
  2. Rechtsklick auf die Miniaturansicht von Teams (bzw. Outlook).
  3. "Show windows from this app on all desktops" wählen (nicht nur "this window" — die App-Variante merkt sich die Einstellung auch für neu geöffnete Fenster).
  4. Wiederholen für Outlook.

Ab jetzt bleiben beide Apps auf ihrer Position sichtbar, egal welchen virtuellen Desktop du gerade aktiv hast — kombiniere das mit der festen Zone aus Lektion 2 auf deinem Portrait-Monitor, dann stehen sie immer am gleichen Fleck.

Unterschied der beiden Optionen "Show this window on all desktops" pinnt nur das aktuell offene Fenster. "Show windows from this app on all desktops" gilt für die ganze App, auch nach Neustart der App — für Outlook/Teams die richtige Wahl.

Kontext-Desktops für deinen Workflow

Ein sinnvoller Zuschnitt für deinen Mix aus Frontend/Backend/Recherche:

DesktopInhalt
FrontendVS Code (Frontend-Projekt) + zugehöriges Terminal mit Copilot CLI
BackendVS Code (Backend-Projekt) + zugehörige Terminal(s)
RechercheBrowser, ggf. zweites Terminal für Experimente

Outlook und Teams tauchen auf allen drei Desktops an derselben Stelle auf, weil sie gepinnt sind — sie zählen quasi nicht als "Inhalt" eines einzelnen Desktops.

Ablauf: einrichten und täglich nutzen

  1. Neue Desktops anlegen: Win+Ctrl+D zweimal (macht insgesamt 3, plus den Standard-Desktop kannst du zu einem der drei umwidmen).
  2. In Task View jeden Desktop per Rechtsklick → Umbenennen auf "Frontend" / "Backend" / "Recherche" setzen.
  3. Auf jedem Desktop die passenden Apps öffnen und in die Zonen aus Lektion 2 einsortieren.
  4. Outlook/Teams einmalig wie in Abschnitt 2 auf "alle Desktops" stellen.
  5. Tagsüber wechseln mit Win+Ctrl+←/→ oder gezielt per Win+Tab, wenn du direkt einen bestimmten Desktop anspringen willst.
Kombiniert mit Workspaces PowerToys Workspaces (Lektion 1) startet alles auf dem aktuell aktiven Desktop — für eine Routine, die beides sauber verzahnt (mehrere kleine Workspaces statt einem großen), siehe Lektion 4.

Glossar

Alle Begriffe des Kurses in je ein bis zwei Sätzen. Die kursiv gesetzten Wörter unter jedem Eintrag sind gebräuchliche Alternativen, die Sie besser vermeiden — sie führen in die Irre.

Die vier Ebenen

LLM · Sprachmodell
Eine Rechenmaschine, die aus Text neuen Text erzeugt. Zustandslos und austauschbar. Im Kurs: der Motor.
Statt: „die KI“, „der Algorithmus“, „das neuronale Netz“
Chatbot
Ein Produkt, das ein Sprachmodell mit einem Gesprächsverlauf verbindet und diesen bei jeder Anfrage vollständig mitschickt. Im Kurs: das Auto, in dem Sie am Steuer sitzen.
Statt: „KI-Assistent“, „Sprachassistent“
Agent
Ein Chatbot, dem eine Werkstatt Werkzeuge gibt und der in einer Schleife läuft, bis eine Aufgabe erledigt ist. Im Kurs: der Werkstattwagen.
Statt: „KI-Assistent“, „Bot“
Autonomer Agent
Ein Agent, der handeln darf, ohne vorher nachzufragen — bis hin zum Weiterlaufen, während niemand zusieht. Autonomie ist eine Erlaubnis, keine Fähigkeit. Im Kurs: der Chauffeur.
Statt: „selbstständige KI“, „starke KI“

Bausteine

Werkstatt · engl. agent harness
Das Programm um das Modell herum, das dessen Vorschläge ausführt und die Rechte kontrolliert. Merksatz: Das Modell schlägt vor, die Werkstatt tut.
Statt: „Framework“, „Runtime“
Kontextfenster
Die maximale Textmenge, die in eine einzelne Anfrage passt — der Schreibtisch. Was nicht darauf liegt, existiert für das Modell nicht.
Statt: „Speicher“, „Gedächtnis“, „Arbeitsspeicher“
Zustandslos · engl. stateless
Zwischen zwei Aufrufen bleibt nichts erhalten. Jede Anfrage trifft auf ein Modell, für das sie die erste ist.
Statt: „vergesslich“, „hat kein Langzeitgedächtnis“
Werkzeug
Eine Fähigkeit, die die Werkstatt anbietet: Dateien lesen, suchen, ein Programm ausführen. Das Modell benennt das Werkzeug — benutzen kann es nur die Werkstatt.
Statt: „Funktion“, „Plugin“, „Skill“ (das ist etwas anderes)
Skill
Ein Ordner mit einer Datei SKILL.md, die in normaler Sprache beschreibt, wie eine wiederkehrende Aufgabe zu erledigen ist. Ein Verfahren zum Aufheben und Weitergeben — kein Programm.
Statt: „Prompt-Vorlage“, „Makro“, „Plugin“
Schrittweises Aufdecken · engl. progressive disclosure
Wie ein Agent viele Skills bereithält, ohne den Schreibtisch zu füllen: erst nur Name und Beschreibung, dann bei Bedarf die volle Anweisung, dann bei Bedarf die zugehörigen Dateien.

Erscheinungen

Context Rot · Kontextfäule
Der gemessene Effekt, dass die Zuverlässigkeit sinkt, je länger die Eingabe wird — auch bei einfachen Aufgaben und lange vor der Kapazitätsgrenze.
Statt: „das Modell wird müde“, „Überlastung“
Themenverschleppung
Ein früheres Thema färbt die Antwort auf ein neues ein, weil beides gleichzeitig auf dem Schreibtisch liegt. Gegenmittel: neuer Chat.
Erfinden · engl. hallucination
Plausibel klingende, aber falsche Angaben. Kein Fehlerzustand, sondern die normale Funktionsweise, angewandt auf eine Wissenslücke.
Statt: „Halluzination“ (klingt krankhaft), „Lüge“ (unterstellt Absicht)
Offenes Modell · engl. open weights
Ein Modell, dessen trainierte Datei zum Herunterladen bereitsteht und das man auf eigener Hardware betreiben kann. Nicht dasselbe wie Open Source: Wie es trainiert wurde, bleibt meist Betriebsgeheimnis.
Statt: „Open-Source-KI“, „freie KI“

Zwei Begriffe sind hier selbst geprägt

„Werkstatt“ und „Themenverschleppung“ finden Sie draußen so nicht — im Deutschen gibt es dafür keine etablierten Wörter. Wenn Sie mit anderen darüber sprechen, nennen Sie einmal den englischen Begriff dazu (agent harness), sonst suchen Ihre Zuhörer vergeblich.

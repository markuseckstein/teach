Bevor Sie das hier auswendig lernen

Tun Sie es nicht. Modellnamen ändern sich im Monatsrhythmus, und die Abstände an der Spitze sind kleiner, als jede Rangliste suggeriert. Was bleibt, sind die drei Fragen aus Lektion 4. Diese Seite ist zum Nachschlagen, nicht zum Merken.

Das Muster, das überall gleich ist

Praktisch jeder Anbieter baut drei Größenklassen. Wenn Sie eine unbekannte Modellbezeichnung sehen, lässt sie sich meist ohne Vorwissen einsortieren:

Klasse Woran man sie erkennt Wofür sie gedacht ist
klein Namenszusätze wie mini, flash, lite, haiku Viel Material, einfache Entscheidung pro Stück: sortieren, umformulieren, Stichworte ziehen, Standardtexte. Sekundenschnell und sehr billig.
mittel der Name ohne Zusatz, oft sonnet, pro, medium Der Alltagsmotor. Deckt schätzungsweise neun von zehn Aufgaben ab, die eine Lehrkraft hat. Hier sollten Sie standardmäßig landen.
groß opus, ultra, pro max, oder ein eigener Name Knifflige Analysen, sehr lange Dokumente, mehrstufige Planung. Langsam, teuer, gründlich. Für den Rest Verschwendung.

Was Sie tatsächlich brauchen

Für eine Lehrkraft gilt fast immer: Ein Abo bei einem der drei großen Anbieter reicht. Welches, entscheidet weniger die Modellqualität als:

  • Was Ihre Schule lizenziert hat. Ein Werkzeug, das Sie benutzen dürfen, schlägt ein besseres, das Sie nicht benutzen dürfen.
  • Ob Sie Agenten wollen. Wer über den Chatbot hinausgehen will, sollte prüfen, welches Angebot dafür einen Weg ohne Terminal bietet (Lektion 8).
  • Wo verarbeitet wird. Siehe Datenschutz-Ampel.

So frischen Sie diese Seite auf

  1. Auf llm-stats.com nachsehen, welche Modelle aktuell oben stehen und was sie kosten.
  2. Bei den drei großen Anbietern die Modellübersicht aufrufen und die Größenklassen den neuen Namen zuordnen.
  3. Die Datumsangabe oben auf dieser Seite ändern.
  4. Nichts anderes anfassen. Wenn Sie merken, dass Sie eine Lektion ändern müssten, war die Lektion zu konkret geschrieben — das wäre dann der eigentliche Fehler.

Browser-Kiosk für die Alarmanzeige

Copy-&-Paste-Blatt. Gilt für Raspberry Pi OS Desktop (Bookworm und neuer) und für Debian-Desktops mit labwc. Auf X11-Systemen gelten andere Befehle — siehe letzter Abschnitt.

Zuerst prüfen: X11 oder Wayland? 
echo $XDG_SESSION_TYPE     # erwartet: wayland
echo $XDG_CURRENT_DESKTOP  # erwartet: labwc (o. wayfire)
which chromium chromium-browser

Steht dort x11, gilt der Abschnitt „Altsysteme" unten. Der Browser heißt je nach Version chromium oder chromium-browser — setz unten den ein, den which gefunden hat.

1 · System vorbereiten

sudo apt update && sudo apt full-upgrade
sudo apt install chromium wlopm      # cec-utils nur bei Fernseher
sudo raspi-config

Im raspi-config-Menü zwei Dinge setzen:

MenüpfadWertWarum
System Options → Boot / Auto LoginDesktop AutologinOhne Sitzung kein Browser. Nach Stromausfall darf niemand ein Passwort tippen.
Display Options → Screen BlankingNoAnzeige darf nicht von selbst schwarz werden.

2 · Autostart

Datei ~/.config/labwc/autostart — anlegen, falls nicht vorhanden:

mkdir -p ~/.config/labwc
nano ~/.config/labwc/autostart

Inhalt (URL in der letzten Zeile anpassen):

#!/bin/sh
# Alarmanzeige — startet neu, falls Chromium abstuerzt
while true; do
  chromium \
    --kiosk \
    --noerrdialogs \
    --disable-infobars \
    --disable-session-crashed-bubble \
    --disable-features=TranslateUI \
    --no-first-run \
    --autoplay-policy=no-user-gesture-required \
    --password-store=basic \
    --check-for-update-interval=604800 \
    --enable-features=OverlayScrollbar \
    --start-maximized \
    "https://time.is/Berlin"
  sleep 5
done &

Was die Schalter tun

SchalterWirkung
--kioskVollbild, keine Adressleiste, keine Tabs
--noerrdialogsUnterdrückt Fehlerdialoge
--disable-infobarsKeine Hinweisleisten oben
--disable-session-crashed-bubbleKein „Seiten wiederherstellen?" nach Stromausfall. Der wichtigste Schalter.
--disable-features=TranslateUIKein Übersetzungs-Popup
--no-first-runÜberspringt den Einrichtungsassistenten
--autoplay-policy=no-user-gesture-requiredErlaubt Tonausgabe ohne vorherigen Klick — nötig für einen Alarmton
--password-store=basicKein Schlüsselbund-Dialog beim Start (gespeichertes Login)
--check-for-update-intervalKein Update-Hinweis mitten im Betrieb
--enable-features=OverlayScrollbarScrollbalken nur wenn nötig
while … sleep 5 … doneStartet die Anzeige neu, falls der Browser stirbt

3 · Abnahme

  1. Stecker ziehen, 10 s warten, einstecken.
  2. Gerät kommt von selbst in die Vollbildanzeige — kein Login, kein Dialog, kein Klick.
  3. Zweites Mal wiederholen. Erst dann gilt es.
  4. Maus und Tastatur abziehen. Ist die Anzeige noch bedienbar genug? (Mauszeiger verstecken ist unter Wayland unbequem — Maus einfach abziehen.)
  5. 30 Minuten stehen lassen: bleibt der Bildschirm an, bleibt die Sitzung angemeldet?

4 · Bildschirm schalten (optional)

Ersetzt „Monitor ON/OFF Modus" des Windows-Monitors. Erst einbauen, wenn Schritt 3 zuverlässig sitzt.

# PC-Monitor: nur Stromsparmodus, Layout bleibt
export XDG_RUNTIME_DIR=/run/user/1000
export WAYLAND_DISPLAY=wayland-0
wlopm --off '*'          # aus
wlopm --on  '*'          # an
wlopm                    # Zustand anzeigen

# NICHT dafuer benutzen — loest den Ausgang aus dem Layout
# wlr-randr --output HDMI-A-1 --off
# Fernseher via HDMI-CEC (Pi 4/5: nur HDMI-Port neben USB-C)
sudo apt install cec-utils
echo 'scan'     | cec-client -s -d 1   # Geraete finden
echo 'on 0'     | cec-client -s -d 1   # TV an
echo 'as'       | cec-client -s -d 1   # auf diesen Eingang schalten
echo 'standby 0'| cec-client -s -d 1   # TV aus
echo 'pow 0'    | cec-client -s -d 1   # Zustand abfragen

5 · Web-Monitor einsetzen

  1. URL, Login-Name und Passwort aus dem Portal holen — siehe PowerAlarm-Bausteine, Abschnitt „Web-Monitor einrichten".
  2. Chromium einmal normal (nicht im Kiosk) starten, Web-Monitor aufrufen, anmelden, Passwort speichern lassen.
  3. Fensterpositionen im Web-Monitor einrichten und mit dem Disketten-Symbol speichern.
  4. URL in ~/.config/labwc/autostart eintragen, Abnahme aus Schritt 3 wiederholen.
  5. Alten Windows-Rechner parallel weiterlaufen lassen, bis mehrere echte Alarme sauber durchgelaufen sind.

Wartung — der eigentliche Grund für den Umbau

# Sicherheitsupdates automatisch einspielen
sudo apt install unattended-upgrades
sudo dpkg-reconfigure -plow unattended-upgrades

Debian/Raspberry Pi OS bekommt Updates ohne Hardware-Zwang — das ist der Unterschied zum festsitzenden Windows 10. Zusätzlich: SD-Karte des Pi einmal fertig konfiguriert klonen und im Schrank ablegen. Ausfall am Einsatztag heißt dann: Karte tauschen, zwei Minuten.

Die X11-Befehle laufen auf einem Wayland-System ohne Fehlermeldung durch und wirken nicht. Wenn eine Anleitung aus dem Netz xset oder unclutter sagt, ist sie älter als Oktober 2024.
